### Düzeltilenler / kalanlar

Yukarıdaki 26 kaynak kodu sorunu düzeltildi. İncelenen alanlarda doğrulanmış ve açık bırakılmış P0/P1 uygulama bug'ı yok. Bir sonraki iş kuyruğunu keyfi olarak yeniden çalıştırmak yerine BullMQ attempt/stall bilgisi kullanılıyor. Farklı crawl kayıtlarının ayrı ayrı kullanıcı tarafından başlatılması mevcut davranış olarak korundu.

**Dependency advisory'leri açık:** `npm audit --omit=dev` 4 high / 0 critical bildiriyor: `@prisma/config`, `deepmerge-ts`, `http-cache-semantics`, `prisma`. Bunlar dört bağımsız production exploit kanıtı değil; bir kısmı aynı transitive advisory zinciridir. Prisma config güvenilir yapılandırma/CLI yolunda; HTTP cache uygulamada açılmamış (`got` cache varsayılanı undefined). Bu incelemede erişilebilir uzaktan exploit doğrulanmadı; güvenlik açığı kapanmış sayılmadı. Dev dahil audit: 16 toplam, 4 critical / 9 high / 3 moderate; critical zincirlerinde Vitest/tinypool ve concurrently/shell-quote bulunuyor. Major upgrade veya force audit fix yapılmadı. Paket güncellemesi bu turda otomatik uygulanmadı; ayrı hedefli dependency düzeltmesi gerektirir.

Mevcut büyük export sınırları (2000 finding / 20000 affected URL / 5000 excluded URL) korundu. Bilinmeyen eski serbest metin TR fallback alır; key veya undefined gösterilmez. Tam tarayıcı ile görsel/etkileşim testi yapılmadı; SSR rendering, HTTP cookie akışı, gerçek API/DB/worker ve export dosyaları test edildi. RAM değeri anlık ölçümdür; uzun süreli yük testi değildir.

## LANGUAGE SUPPORT

**TR:** Varsayılan dil; mevcut `/` URL'si ve Türkçe metin anlamı korundu.

**EN:** `/en/` public İngilizce landing; profesyonel SEO terminolojisiyle UI ve rule sunumu İngilizce. Teknik rule code, severity enum, fingerprint, URL, gözlenen teknik değerler değişmiyor. Yeni kural eklenmedi.

**Language switch:** Mevcut stile uygun TR / EN bağlantıları. `/api/language` bir yıllık HttpOnly, SameSite=Lax cookie yazar; HTTPS'te Secure. Redirect aynı origin/yol ile sınırlı. SSR cookie/header locale seçer, html lang doğru; ilk render dili server'da belirlenir. Public `/` her zaman TR, `/en/` EN; route tercihi sonraki raporlara taşınır. Sahte locale header proxy tarafından kaldırılır.

**URL yapısı:** https://seo.yasinkocak.com.tr/ ve https://seo.yasinkocak.com.tr/en/. Mevcut crawl/rapor/taramalar/karsilastir yolları korundu; rapor dilinde cookie veya export lang parametresi kullanılır. Türkçe URL'ler kırılmadı.

**hreflang/canonical:** Public sayfalarda kendi canonical'ı; tr/en/x-default alternate'ları. Kullanıcıya özel crawl/report/history/compare metadata'sında noindex. `/en/` doğrudan HTTP 200.

**Çevrilen alanlar:** Navigation, hero, form/validation/placeholders/buttons, başlatma/loading/progress/status/errors, history/dashboard/crawl/report/compare, finding title/description/recommendation/evidence etiketleri, severity ve passed metinleri, tablo/filter/pagination/export, empty/error/not-found, footer ve metadata. Rule metinleri ortak sözlükte; eski DB'deki Türkçe finding metinleri sunumda çevrilebilir; DB migration gerekmedi. Worker operasyon logları son kullanıcı arayüzü değildir ve İngilizceye taşınmadı.

**Translation yapısı:** `packages/shared/src/i18n/{tr,en,index}.ts`; ~382 mesaj + özet mesajları. Dış kütüphane yok. Kullanıcı metinleri merkezi yapıdan alınır; interpolasyon ve eski persisted metin eşleştirmesi desteklenir. Eksik anahtarda güvenli fallback; undefined, key adı ve object string'i UI'a sızmaz. Key ve placeholder parity test edildi.

**Export language desteği:** PDF / Word / CSV seçili dilde üretilir. Başlıklar, severity display, açıklama, öneri, özet/tarih ve kanıt etiketleri yerelleştirilir; gözlenen URL/değer ve teknik internal field adları korunur. CSV teknik contract'ı değişmedi. Dosya adlarında locale tarihinin `/` oluşturması engellendi.

**Translation testleri:** TR/EN SSR, public metadata, language cookie/redirect, key + placeholder parity, missing key/invalid value fallback, legacy DB metni, finding teknik kimliği ve iki dil export testleri PASS.
